## How to use it

Finish the original lab for a project, then work through its second block in order. Budget approximately 9–12 additional hours per project; the capstone may take longer when application setup is required. Keep answers closed until you have your own attempt. Use the [progress tracker](TRACKER.md) and preserve the original tracker's history.

Twenty new labs run with Node alone. Starters intentionally fail; sealed references are separate. Source maps link back to each real repository. TypeScript exercises require both a type sketch and runtime reasoning; GitJira follows its current JavaScript/JSDoc conventions. Database, browser, and provider guarantees remain separate from pure-model tests.

The [verification and size report](VALIDATION.md) records test results, local-link checks, preservation checks, and the measured growth of each original pack. Counts refer to Markdown words in the reinforcement packs, not to the entire pre-existing Opus curriculum. Human mastery remains unassessed.
