Useful statuses are studied, explained, independently modeled, and application-verified. Attach evidence to the last two and keep the environment explicit. A source trace, a pure-model run, and a browser/database observation support different claims.

After a session, record one sentence you can now explain more precisely. Then choose a changed fixture for tomorrow and a different project for later transfer. Preserve the original prediction so the log shows how your reasoning developed rather than only displaying corrected answers.

If a method did not help, switch the representation: a diagram for hidden ownership, a table for timing, a small program for a branch condition, or a spoken explanation for vague language. Record the useful distinction you found, not a permanent label about how you learn.
